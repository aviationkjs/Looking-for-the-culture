# 우리 가족 문화탐방 (Looking for the culture)

가족여행으로 가는 문화유적을 **장소별로 하나씩 쌓아 가는** 초등 저학년용 HTML 학습 모음입니다.
대문에서 장소를 고르면 짧은 **그림 해설(모션그래픽)** 을 보고, 쉬운 **퀴즈**를 풀어 별을 모읍니다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 초등 1~2학년 (부모와 함께 보기) |
| 장소당 분량 | 그림 해설 5장면 약 2분 + 퀴즈 6문제 약 3분 |
| 실행 | GitHub Pages 또는 내려받아 `index.html` 더블클릭 (인터넷 없이도 동작) |
| 기술 | HTML + CSS + 순수 JavaScript, 외부 라이브러리·이미지·음원·글꼴 파일 없음 |
| 현재 장소 | 서대문형무소 (준비 중: 경복궁) |

---

## 1. 바로 보기

### GitHub Pages로 열기 (추천)
1. 저장소 **Settings → Pages** 로 이동
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 선택 후 Save
3. 1~2분 뒤 `https://aviationkjs.github.io/Looking-for-the-culture/` 에서 대문이 열립니다

### 내 컴퓨터에서 열기
저장소를 내려받아(Code → Download ZIP) 압축을 풀고 `index.html` 을 더블클릭합니다.
데이터를 `.json` 이 아닌 `.js` 로 두었기 때문에 `file://` 로 열어도 그대로 동작합니다.

## 2. 폴더 구조

```
Looking-for-the-culture/
├─ index.html              대문 (장소 카드 목록, 모은 별 표시)
├─ places.js               대문에 보일 장소 목록 ← 새 장소 추가 시 한 줄 추가
├─ README.md
├─ common/                 모든 장소가 함께 쓰는 파일 (보통 고칠 일 없음)
│  ├─ tour.css             디자인 + 그림 움직임(a-*) 클래스
│  └─ tour.js              엔진: 시작 화면 → 그림 해설 → 퀴즈 → 결과
└─ places/
   ├─ _template/           새 장소를 만들 때 복사하는 틀
   │  ├─ index.html
   │  └─ data.js
   └─ seodaemun/           서대문형무소
      ├─ index.html        페이지 틀 (제목만 다름)
      └─ data.js           장면 글 · 그림(SVG) · 퀴즈 · 참고 자료
```

**원칙: 장소마다 바뀌는 것은 `places/<장소>/data.js` 하나뿐입니다.**
화면 흐름, 버튼, 퀴즈 채점, 별 저장은 모두 `common/tour.js` 가 처리합니다.

## 3. 화면 흐름

```
대문 ─▶ 시작 화면 ─▶ 그림 해설 (5장면) ─▶ "퀴즈 풀어 볼까요?" ─▶ 퀴즈 (6문제) ─▶ 결과 (별 1~3개)
          │                                                              │
          └──── [바로 퀴즈 풀기] ────────────────────────────────▶        ├─ [다시 보면 좋은 장면] → 그 장면만 보고 결과로 돌아옴
                                                                         ├─ [다시 풀기]
                                                                         └─ [대문으로]
```

- **읽어 주기**: 오른쪽 위 🔊 버튼. 브라우저에 들어 있는 한국어 음성으로 자막과 문제를 읽어 줍니다(음원 파일 0KB).
  켜져 있으면 다 읽은 뒤 다음 장면으로, 꺼져 있으면 장면의 `sec` 초가 지나면 넘어갑니다.
- **해설 조작**: ◀ 이전 / ⏸ 멈춤 / ▶ 다음. 키보드 ← → 스페이스도 됩니다.
- **퀴즈**: 처음 틀리면 "다시 생각해 볼까요?"로 한 번 더 기회. 두 번째에는 정답과 설명을 보여 줍니다.
  점수는 **처음 고른 답**으로만 셉니다.
- **별**: 다 맞으면 ★3, 1~2개 틀리면 ★2, 그 밖은 ★1 (별 0개는 없음). 가장 좋은 기록이 브라우저에 저장되어 대문 카드에 보입니다.
- 주소 끝에 `#quiz` 를 붙이면 바로 퀴즈로 시작합니다. 예: `places/seodaemun/index.html#quiz`

## 4. 새 장소 추가하기 (체크리스트)

예시로 경복궁(`gyeongbokgung`)을 추가한다고 하면:

1. **폴더 복사** — `places/_template/` 을 복사해 `places/gyeongbokgung/` 으로 이름 바꾸기
   (폴더 이름 = 영어 소문자, 띄어쓰기 대신 `-`)
2. **`index.html`** — `<title>` 의 "장소 이름"만 바꾸기. 나머지는 그대로
3. **`data.js`** — 아래 「5. data.js 형식」에 맞춰 내용 채우기
4. **`places.js`** — 장소 한 줄 추가 (이미 '준비 중'으로 있으면 `ready: true` 로 바꾸기)
   ```js
   { id: 'gyeongbokgung', name: '경복궁', region: '서울 종로구', icon: '👑',
     color: '#2f5d8a', path: 'places/gyeongbokgung/index.html', ready: true },
   ```
   - `id` 는 `data.js` 의 `id` 와 **반드시 같게** (별 기록을 이 이름으로 저장)
   - `path` 는 `index.html` 까지 적기 (폴더만 적으면 `file://` 에서 안 열림)
   - `color` 는 `data.js` 의 `theme.main` 과 같게
5. **확인** — 「8. 올리기 전 확인」 목록을 하나씩 체크
6. **커밋** — `장소 추가: 경복궁 (장면 5, 문제 6)` 처럼 무엇을 얼마나 추가했는지 적기

## 5. `data.js` 형식

```js
window.TOUR_DATA = {
  id: 'seodaemun',                 // 폴더 이름과 같은 영어 id
  name: '서대문형무소',             // 화면 위 제목, 대문 카드 이름
  theme: { main: '#8b3a2b' },      // 버튼·제목 색 (장소의 대표색)
  intro: '시작 화면 소개 1~2문장',
  cover: S1,                       // 시작 화면 그림 (보통 첫 장면 그림을 재사용)

  scenes: [                        // 그림 해설 장면 (5개 권장)
    { id: 1,                       // 1부터 차례대로
      title: '빨간 벽돌 감옥',      // 장면 제목 (결과 화면 '다시 볼 장면' 버튼에도 쓰임)
      sec: 22,                     // 읽어 주기를 껐을 때 머무는 시간(초)
      art: S1,                     // 장면 그림 SVG 문자열
      lines: ['아주 오래전 1908년,', '서울에 큰 감옥이 생겼어요.'] }  // 자막 한 줄씩
  ],

  questions: [                     // 퀴즈 (6문제 권장)
    { id: 'sdm-q1',                // 장소 약자-q번호
      ageGroup: 'CHILD', difficulty: 'EASY',
      scene: 1,                    // 이 문제의 근거 장면 번호 (틀리면 이 장면을 다시 보라고 안내)
      text: '감옥 건물은 무엇으로 지었을까요?',
      options: ['나무', '빨간 벽돌', '유리'],
      answer: 1,                   // 정답 위치, 0부터 셈
      explanation: '빨간 벽돌로 지어서 지금도 빨간 건물이에요.' }
  ],

  sources: [                       // 어른용 참고 자료 (시작 화면 아래 접힌 목록)
    { title: '글 제목 — 출처', url: 'https://...' }
  ]
};
```

- **O/X 문제**는 `options: ['O', 'X']` 로 쓰면 큰 O/X 버튼으로 바뀝니다.
- 문제 형식은 [family-trip](https://github.com/aviationkjs/family-trip) 저장소의 `quiz.json` 과 같습니다
  (`scene` 만 추가). 그쪽 문제은행으로 그대로 옮겨 쓸 수 있습니다.
- `data.js` 는 `(() => { ... })();` 로 감싸서, 그림 조각을 변수(`S1`, `BRICK` 등)로 만들어 여러 번 재사용합니다.

## 6. 장면 그림 그리는 법 (SVG)

- 크기는 모두 **`viewBox="0 0 400 240"`** (가로:세로 = 5:3). 화면에 맞춰 자동으로 늘어납니다.
- 사진·그림 파일은 쓰지 않고 **도형(rect, circle, path, polygon, text)** 으로만 그립니다 → 용량이 작고 저작권 걱정이 없습니다.
- 사람은 **얼굴 없는 동그란 실루엣**으로만 그립니다 (실제 인물 얼굴·사진 금지).
- 장면마다 `<defs>` 안에 필요한 무늬(`pattern`)·기호(`symbol`)를 넣습니다. 한 번에 한 장면만 화면에 있으므로 id가 겹쳐도 괜찮습니다.

### 움직임 붙이기
SVG 요소에 `class="a-이름"` 과 `style="--d:시작지연"` 을 붙입니다.

```html
<rect class="a-drop" style="--d:1.2s" x="110" y="152" width="200" height="24" fill="url(#brk)"/>
```

| 클래스 | 움직임 | 쓰임 예 |
| --- | --- | --- |
| `a-drop` | 위에서 툭 떨어져 쌓임 | 벽돌 줄, 지붕 |
| `a-pop` | 0에서 톡 커지며 나타남 | 창문, 연도 글자, 해 |
| `a-fade` | 서서히 나타남 | 배경 요소, 사람 |
| `a-rise` | 아래에서 위로 떠오르며 사라짐 (반복) | "만세!" 글자 |
| `a-wave` | 깃발처럼 펄럭임 (반복) | 태극기 |
| `a-jump` | 살짝 콩콩 뜀 (반복) | 만세 부르는 사람 |
| `a-glow` | 빛이 커졌다 작아짐 (반복) | 창살 너머 빛 |
| `a-bloom` | 돌면서 피어남 | 무궁화 |
| `a-shutL` / `a-shutR` | 왼쪽/오른쪽에서 닫힘 | 문 |
| `a-drift` | 왼쪽에서 밀려옴 | 구름 |
| `a-dim` | 화면이 어두워짐 (덮개 rect에) | 슬픈 장면 |
| `a-bright` | 어둡던 화면이 밝아짐 (덮개 rect에) | 마지막 장면 |

**주의:** 움직임은 CSS `transform` 을 쓰므로, `transform="translate(...)"` 로 위치를 잡은 요소에 직접 붙이면 위치가 사라집니다.
위치는 바깥 `<g transform>` 에, 움직임은 안쪽 요소에 붙이세요.

```html
<g transform="translate(60 40)"><use href="#tg" width="90" height="60" class="a-wave"/></g>
```

자막은 그림이 어느 정도 움직인 뒤 나오도록, 중요한 그림은 `--d` 를 0~3초 사이로 잡습니다.
움직임 줄이기 설정을 켠 기기에서는 모든 움직임이 자동으로 꺼집니다.

## 7. 글쓰기 규칙 (초등 저학년)

**해설 자막**
- 해요체, 한 줄 20자 안팎, 한 장면 2~3줄
- 연도는 꼭 필요한 것만 (장소 전체에서 1~2개). "아주 오래전 1908년," 처럼 쉬운 말과 함께
- 어려운 낱말은 쉬운 말로: 투옥 → 갇혔어요, 순국 → (쓰지 않거나 부모 설명에 맡김), 개관 → 문을 열었어요
- 장면 순서는 시간 순서: **생김 → 무슨 일 → 대표 인물/사건 → 지금 모습 → 기억하기**

**아픈 역사를 다룰 때**
- 고문·처형·죽음 장면은 그리거나 쓰지 않습니다. "갇혔어요", "포기하지 않았어요"처럼 마음과 행동에 초점을 둡니다
- 마지막 장면은 항상 "지금은 무엇이 되었는지 + 우리가 기억해요"로 밝게 마무리합니다
- 미워하는 마음보다 **나라를 사랑한 사람들을 기억하는 마음**을 남기는 것이 목표입니다

**퀴즈**
- 6문제: 고르기 4 + O/X 2, 보기는 3개
- **해설에 나온 내용만** 묻기 (해설을 보면 다 맞힐 수 있어야 함)
- 정답 위치를 고르게 나누기 (예: 1, 0, 2, 0, 1, 2) — 한 번호에 몰리지 않게
- 틀린 보기는 아이가 웃으며 고를 수 있을 만큼 분명히 다르게 (예: 풍선 / 꽃 / 태극기)
- 흔한 오해를 바로잡는 O/X 하나 넣기 (예: "갇힌 사람은 모두 나쁜 사람이다 → X")
- 설명은 한 문장, 해요체

**사실 확인**
- 연도·이름은 공공기관·지자체·언론 등 믿을 만한 자료 2곳 이상에서 확인하고 `sources` 에 남깁니다
- 자료끼리 다른 내용(예: 해방 직후 명칭)은 퀴즈에 넣지 않습니다

## 8. 올리기 전 확인

- [ ] `index.html` 더블클릭(`file://`)으로 대문 → 장소 → 해설 → 퀴즈 → 결과 → 대문이 끝까지 됨
- [ ] 읽어 주기 켬/끔 둘 다 장면이 자동으로 넘어감
- [ ] 휴대폰 세로 화면에서 글자·버튼이 잘리지 않음
- [ ] 모든 문제의 정답 번호(`answer`)가 맞음, 정답 위치가 한쪽에 몰리지 않음
- [ ] 문제마다 `scene` 이 실제로 그 내용을 다룬 장면을 가리킴
- [ ] `places.js` 의 `id`·`path` 가 폴더와 일치
- [ ] 브라우저 개발자 도구(F12) 콘솔에 빨간 오류 없음
- [ ] 용량 확인: 장소 폴더 50KB 이하

용량 확인 명령 (Git Bash / macOS / Linux):
```bash
du -sh places/*/ common/
```

## 9. 용량 원칙

GitHub 저장소와 Pages를 가볍게 유지하기 위해:

| 구분 | 목표 | 현재 |
| --- | --- | --- |
| 공통 (`common/`) | 30KB 이하 | 약 18KB |
| 장소 1곳 (`places/<장소>/`) | 50KB 이하 | 서대문형무소 약 12KB |
| 대문 + 목록 | 5KB 이하 | 약 2KB |

- 사진(JPG/PNG), 음원(MP3), 글꼴 파일, 외부 라이브러리(CDN 포함)는 넣지 않습니다
- 소리는 브라우저 내장 음성(읽어 주기)과 WebAudio로 만든 효과음만 씁니다
- 꼭 이미지가 필요하면 SVG로 직접 그리고, 그래도 필요하면 10KB 이하 WebP 하나까지만

## 10. 브라우저에 저장되는 것

`localStorage` 에 아래 두 가지만 저장합니다 (서버로 보내는 정보 없음).

| 키 | 값 |
| --- | --- |
| `lftc:stars:<장소 id>` | 그 장소에서 받은 가장 좋은 별 수 (1~3) |
| `lftc:voice` | 읽어 주기 `on` / `off` |

기록을 지우려면 브라우저 개발자 도구 → Application → Local Storage 에서 `lftc:` 로 시작하는 항목을 지웁니다.
