# 우리 가족 문화탐방 (Looking for the culture)

가족여행으로 가는 문화유적을 **장소별로 하나씩 쌓아 가는** 초등 저학년용 HTML 학습 모음입니다.
대문에서 장소를 고르고, 장소 안의 **이야기**를 골라 짧은 **그림 해설(모션그래픽)** 을 본 뒤 쉬운 **퀴즈**를 풀어 별을 모읍니다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 초등 1~2학년 (부모와 함께 보기) |
| **주 사용 기기** | **휴대폰 세로 화면 (6인치, 360×740) — 「2. 화면 기준」을 반드시 지킬 것** |
| 이야기당 분량 | 그림 해설 5장면 약 2분 + 퀴즈 6문제 약 3분 |
| 실행 | GitHub Pages 또는 내려받아 `index.html` 더블클릭 (인터넷 없이도 동작) |
| 기술 | HTML + CSS + 순수 JavaScript, 외부 라이브러리·이미지·음원·글꼴 파일 없음 |

### 현재 장소와 이야기

| 장소 | 이야기 (폴더) | 역사관에서 찾아볼 곳 | 장면 | 문제 |
| --- | --- | --- | --- | --- |
| 서대문형무소 | 서대문형무소 이야기 (`main`) | 처음 보는 친구용 | 5 | 6 |
| | 여옥사 8호 감방 (`women8`) | 여옥사 | 5 | 6 |
| | 감옥 건물의 비밀 (`building`) | 중앙사 · 격벽장 · 망루 | 5 | 6 |
| | 독립문 이야기 (`gate`) | 독립공원 입구 | 5 | 6 |
| 경복궁 | (준비 중) | | | |

새 장소·이야기를 추가하면 이 표도 함께 고쳐 주세요.

## 1. 바로 보기

### GitHub Pages로 열기 (추천 — 휴대폰에서 주소로 바로 열림)
1. 저장소 **Settings → Pages** 로 이동
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 선택 후 Save
3. 1~2분 뒤 `https://aviationkjs.github.io/Looking-for-the-culture/` 에서 대문이 열립니다
4. 휴대폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다

### 내 컴퓨터에서 열기
저장소를 내려받아(Code → Download ZIP) 압축을 풀고 `index.html` 을 더블클릭합니다.
데이터를 `.json` 이 아닌 `.js` 로 두었기 때문에 `file://` 로 열어도 그대로 동작합니다.

## 2. 화면 기준 (휴대폰 우선) ★

대부분 **휴대폰 세로 화면**으로 보기 때문에, 모든 화면은 아래 기준에 맞춰 만들고 확인합니다.

| 구분 | 기준 |
| --- | --- |
| **기준 화면** | **6인치 휴대폰 세로, 360 × 740 CSS 픽셀** (갤럭시 S·A 시리즈급) |
| 최소 화면 | 320 × 640 — 가로 넘침·잘림 없어야 함 |
| 큰 화면 | 태블릿·PC는 가운데 최대 900px 폭으로 보여 줌 (따로 맞출 필요 없음) |
| 휴대폰 전환점 | CSS `@media (max-width:480px)` — 돌아가기 버튼은 아이콘만 |
| 아주 좁은 화면 | CSS `@media (max-width:400px)` — 🔊 읽기 버튼도 아이콘만 (화면 확대·큰 글꼴 설정 대비, 폭 250px까지 확인) |

**휴대폰에서 꼭 지킬 것**
- **한 화면에 스크롤 없이** 위 막대 → 그림 → 자막 → ◀ ⏸ ▶ 버튼이 모두 보일 것 (해설 화면)
- 위 막대에는 **돌아가기 · 제목 · 🔊**가 한 줄에 다 보일 것. 제목이 길면 `…` 로 줄어들고, 버튼은 절대 화면 밖으로 밀려나지 않음
- 버튼(터치 영역) 높이 **48px 이상**, 위 막대 버튼 44px 이상
- 자막 글자 19~24px, 문제 글자 21~26px. 한국어는 낱말 단위로 줄바꿈(`word-break: keep-all`)
- 자막 한 줄은 **18자 안팎**으로 쓰기 (360px에서 한 줄에 들어가는 길이). 길면 두 줄로 나뉘어도 되지만 한 장면 전체가 5줄을 넘지 않게
- 그림 속 글자는 360px 화면에서 그림이 약 0.85배로 줄어드는 것을 생각해 **font-size 16 이상**
- 대문·작은 대문 카드는 휴대폰에서 **2열**

**고친 뒤 휴대폰에 바로 반영되게 (캐시 버전)**
- 휴대폰 브라우저는 예전 `tour.css`·`tour.js` 를 기억(캐시)해 두었다가 그대로 쓰는 일이 있습니다.
- 그래서 모든 HTML에서 파일 뒤에 버전을 붙입니다: `tour.css?v=2`, `tour.js?v=2`, `data.js?v=2` …
- **`common/` 이나 `data.js` 를 고쳐서 올릴 때는 모든 HTML의 `?v=` 숫자를 하나 올립니다.** (현재 `v=2`)
  ```bash
  # 예: v=2 → v=3 (Git Bash / macOS / Linux)
  grep -rl '?v=2"' --include=*.html . | xargs sed -i 's/?v=2"/?v=3"/g'
  ```
- 그래도 옛 화면이 보이면 휴대폰 브라우저에서 새로고침하거나, 주소 끝에 `?1` 을 붙여 열어 봅니다.

**확인 방법**
- PC 크롬: F12 → 기기 툴바(Ctrl+Shift+M) → 크기 **360 × 740** 으로 설정해 처음부터 끝까지 눌러 보기, **320 × 640** 도 한 번
- 실제 휴대폰: GitHub Pages 주소로 열어 🔊 읽기 소리까지 확인

## 3. 폴더 구조

```
Looking-for-the-culture/
├─ index.html                대문 (장소 카드, 모은 별)
├─ places.js                 대문에 보일 장소 목록 ← 새 장소 추가 시 한 줄
├─ README.md
├─ common/                   모든 장소가 함께 쓰는 파일 (보통 고칠 일 없음)
│  ├─ tour.css               디자인 + 휴대폰 화면 + 그림 움직임(a-*) 클래스
│  ├─ tour.js                엔진: 시작 화면 → 그림 해설 → 퀴즈 → 결과
│  ├─ hub.js                 카드 목록 (대문·작은 대문 공통)
│  └─ art.js                 공통 그림 조각 (벽돌·돌 무늬, 태극기, 무궁화, 사람, 하트, 글자)
└─ places/
   ├─ _template/             새 장소를 만들 때 통째로 복사하는 틀
   │  ├─ index.html          작은 대문
   │  ├─ stories.js          이야기 목록
   │  └─ main/               첫 이야기 (index.html + data.js)
   └─ seodaemun/             서대문형무소
      ├─ index.html          작은 대문 (이야기 카드 4개)
      ├─ stories.js          이야기 목록
      ├─ main/               서대문형무소 이야기
      ├─ women8/             여옥사 8호 감방
      ├─ building/           감옥 건물의 비밀
      └─ gate/               독립문 이야기
          (각 폴더 = index.html + data.js)
```

**원칙: 이야기마다 바뀌는 것은 `data.js` 하나뿐입니다.**
화면 흐름, 버튼, 읽어 주기, 퀴즈 채점, 별 저장은 모두 `common/tour.js` 가 처리합니다.

## 4. 화면 흐름

```
대문 ─▶ 장소의 작은 대문 ─▶ 이야기 시작 화면 ─▶ 그림 해설(5장면) ─▶ 퀴즈(6문제) ─▶ 결과(별 1~3개)
  ▲            ▲                    └─ [바로 퀴즈 풀기] ─────────────▶            │
  │            └──────────────── [◀ 장소이름] (위 막대 / 결과 화면) ◀────────────┤
  └─ [🏠 대문] (작은 대문 위)                                [다시 보면 좋은 장면] → 그 장면만 보고 결과로
```

- **🔊 읽기**: 위 막대 오른쪽. 브라우저에 들어 있는 한국어 음성으로 자막과 문제를 읽어 줍니다(음원 파일 0KB).
  켜져 있으면 다 읽은 뒤 다음 장면으로, 꺼져 있으면(🔇) 장면의 `sec` 초가 지나면 넘어갑니다.
- **해설 조작**: ◀ 이전 / ⏸ 멈춤 / ▶ 다음. 키보드 ← → 스페이스도 됩니다.
- **퀴즈**: 처음 틀리면 "다시 생각해 볼까요?"로 한 번 더 기회. 두 번째에는 정답과 설명을 보여 줍니다. 점수는 **처음 고른 답**으로만 셉니다.
- **별**: 다 맞으면 ★3, 1~2개 틀리면 ★2, 그 밖은 ★1 (별 0개는 없음). 이야기마다 가장 좋은 기록이 저장되고,
  작은 대문 카드에는 이야기별 별, 대문 카드에는 장소의 별 합계(예: ★ 9 / 12)가 보입니다.
- 주소 끝에 `#quiz` 를 붙이면 바로 퀴즈로 시작합니다. 예: `places/seodaemun/women8/index.html#quiz`

## 5. 새 이야기 추가하기 (이미 있는 장소에)

예: 서대문형무소에 `cards`(5,000장의 얼굴 카드) 이야기를 추가

1. **폴더 복사** — `places/seodaemun/women8/` 을 복사해 `places/seodaemun/cards/` 로 이름 바꾸기
2. **`index.html`** — `<title>` 만 바꾸기 (`homeLabel: '◀ 서대문형무소'` 는 그대로)
3. **`data.js`** — 「7. data.js 형식」에 맞춰 내용 바꾸기. `id` 는 `'seodaemun-cards'` 처럼 **장소id-주제**
4. **`places/seodaemun/stories.js`** — 한 줄 추가
   ```js
   { id: 'seodaemun-cards', name: '5,000장의 얼굴 카드', sub: '찾아볼 곳: 전시관 추모 공간', icon: '🪪',
     color: '#6b4a3a', path: 'cards/index.html', ready: true },
   ```
5. **`places.js`** — 서대문형무소 줄의 `stories` 배열에 `'seodaemun-cards'` 추가 (대문 별 합계용)
6. **README** 의 「현재 장소와 이야기」 표에 한 줄 추가
7. 「10. 올리기 전 확인」 체크 → 커밋 `이야기 추가: 서대문형무소/5,000장의 얼굴 카드 (장면 5, 문제 6)`

## 6. 새 장소 추가하기

예: 경복궁(`gyeongbokgung`)

1. **폴더 복사** — `places/_template/` 을 통째로 복사해 `places/gyeongbokgung/` 으로 이름 바꾸기 (영어 소문자, 띄어쓰기 대신 `-`)
2. **`index.html`(작은 대문)** — `<title>`, `<h1>`, `body` 의 `--main` 색 바꾸기
3. **`stories.js`** — 첫 이야기 줄의 `id` 를 `'gyeongbokgung'`, `name` 을 `'경복궁 이야기'` 로
4. **`main/index.html`** — `<title>` 과 `homeLabel: '◀ 경복궁'` 바꾸기
5. **`main/data.js`** — 내용 채우기 (`id: 'gyeongbokgung'`)
6. **`places.js`** — 경복궁 줄의 `ready: true`, `stories: ['gyeongbokgung']` (이야기가 늘면 계속 추가)
7. 이야기를 더 만들 때는 「5. 새 이야기 추가하기」 순서대로

## 7. `data.js` 형식

```js
(() => {
  const { brick, person, text, svg } = window.ART;   // 공통 그림 조각 (8번 참고)
  const S1 = svg(brick(), `...장면 그림...`);

  window.TOUR_DATA = {
    id: 'seodaemun-women8',          // stories.js 의 id 와 같게 (별 기록 이름)
    name: '여옥사 8호 감방',          // 위 막대 제목, 시작 화면 제목 (휴대폰에서 10자 안팎 권장)
    theme: { main: '#b0456e' },      // 버튼·제목 색 (stories.js 의 color 와 같게)
    intro: '시작 화면 소개 1~2문장. 역사관에서 찾아볼 곳을 알려 주면 좋아요.',
    cover: S1,                       // 시작 화면 그림 (보통 첫 장면 그림)

    scenes: [                        // 그림 해설 장면 (5개 권장)
      { id: 1,                       // 1부터 차례대로
        title: '여자 감옥, 여옥사',   // 장면 제목 (결과 화면 '다시 볼 장면' 버튼에도 쓰임)
        sec: 20,                     // 읽어 주기를 껐을 때 머무는 시간(초)
        art: S1,                     // 장면 그림 SVG 문자열
        lines: ['서대문형무소에는', '여자들이 갇힌 감옥도 있었어요.'] }  // 자막 한 줄씩 (18자 안팎)
    ],

    questions: [                     // 퀴즈 (6문제 권장)
      { id: 'sdm8-q1',               // 이야기 약자-q번호
        ageGroup: 'CHILD', difficulty: 'EASY',
        scene: 1,                    // 근거 장면 번호 (틀리면 이 장면을 다시 보라고 안내)
        text: '여자들이 갇힌 감옥의 이름은 무엇일까요?',
        options: ['여옥사', '중앙사', '공작사'],
        answer: 0,                   // 정답 위치, 0부터 셈
        explanation: '여자들이 갇힌 감옥은 ‘여옥사’예요.' }
    ],

    sources: [                       // 어른용 참고 자료 (시작 화면 아래 접힌 목록)
      { title: '글 제목 — 출처', url: 'https://...' }
    ]
  };
})();
```

- **O/X 문제**는 `options: ['O', 'X']` 로 쓰면 큰 O/X 버튼으로 바뀝니다.
- 문제 형식은 [family-trip](https://github.com/aviationkjs/family-trip) 저장소의 `quiz.json` 과 같습니다 (`scene` 만 추가). 그대로 옮겨 쓸 수 있습니다.
- 이야기 `index.html` 은 `common/art.js` → `data.js` → `common/tour.js` 순서로 불러옵니다.

## 8. 장면 그림 그리는 법 (SVG)

- 크기는 모두 **`viewBox="0 0 400 240"`** (가로:세로 = 5:3). 화면 폭에 맞춰 자동으로 늘고 줄어듭니다.
- 사진·그림 파일은 쓰지 않고 **도형(rect, circle, path, polygon, text)** 으로만 그립니다 → 용량이 작고 저작권 걱정이 없습니다.
- 사람은 **얼굴 없는 실루엣**으로만 그립니다 (실제 인물 얼굴·사진 금지).
- 그림 속 글자는 **16 이상** (휴대폰에서 줄어듦), 중요한 글자는 20~34.

### 공통 그림 조각 `window.ART` (`common/art.js`)

| 이름 | 쓰는 법 | 설명 |
| --- | --- | --- |
| `svg(defs, body)` | `svg(brick(), '<rect .../>')` | `<svg viewBox="0 0 400 240">` 로 감싸기 |
| `brick(id?)` | defs에 넣고 `fill="url(#brk)"` | 빨간 벽돌 무늬 |
| `stone(id?)` | defs에 넣고 `fill="url(#stn)"` | 회색 큰 돌 무늬 |
| `FLAG` | defs에 넣고 `<use href="#tg" width="90" height="60"/>` | 태극기 (3:2, 건곤감리 위치 정확) |
| `FLOWER` + `flower(x,y,지연,크기)` | defs에 `FLOWER`, 본문에 `flower(...)` | 무궁화가 피어남 |
| `person(x,y,색,팔들기,지연)` | 발 위치 기준 | 사람 실루엣 |
| `girl(x,y,색,팔들기,지연)` | 발 위치 기준 | 치마 입은 사람 실루엣 |
| `heart(x,y,크기,색,클래스,지연)` | | 하트 |
| `text(x,y,글,크기,색,클래스,지연)` | 가운데 정렬 | 굵은 글자 |

### 움직임 붙이기
SVG 요소에 `class="a-이름"` 과 `style="--d:시작지연"` 을 붙입니다.

```html
<rect class="a-drop" style="--d:1.2s" x="110" y="152" width="200" height="24" fill="url(#brk)"/>
```

| 클래스 | 움직임 | 쓰임 예 |
| --- | --- | --- |
| `a-drop` | 위에서 툭 떨어져 쌓임 | 벽돌 줄, 지붕, 돌 |
| `a-pop` | 0에서 톡 커지며 나타남 | 창문, 연도 글자, 해 |
| `a-fade` | 서서히 나타남 | 배경 요소, 사람, 불빛 |
| `a-out` | 서서히 사라짐 | 없어진 건물(영은문) |
| `a-rise` | 아래에서 위로 떠오르며 사라짐 (반복) | "만세!", 음표, 하트 |
| `a-wave` | 깃발처럼 펄럭임 (반복) | 태극기 |
| `a-jump` | 살짝 콩콩 뜀 (반복) | 만세·노래하는 사람 |
| `a-glow` | 빛이 커졌다 작아짐 (반복) | 창살 너머 빛 |
| `a-sweep` | 위쪽 꼭짓점을 축으로 좌우로 흔들림 (반복) | 망루 불빛 |
| `a-bloom` | 돌면서 피어남 | 무궁화 |
| `a-shutL` / `a-shutR` | 왼쪽/오른쪽에서 닫힘 | 문 |
| `a-drift` | 왼쪽에서 밀려옴 | 구름 |
| `a-dim` | 화면이 어두워짐 (덮개 rect에) | 슬픈 장면 |
| `a-bright` | 어둡던 화면이 밝아짐 (덮개 rect에) | 마지막 장면 |

**주의:** 움직임은 CSS `transform` 을 쓰므로, `transform="translate(...)"` 로 위치를 잡은 요소에 직접 붙이면 위치가 사라집니다.
위치는 바깥 `<g transform>` 에, 움직임은 안쪽 요소에 붙이세요.

```html
<g transform="translate(60 40)"><use href="#tg" width="90" height="60" class="a-wave"/></g>
```

중요한 그림은 `--d` 를 0~3초 사이로 잡아, 자막이 나올 즈음 그림이 완성되게 합니다.
움직임 줄이기 설정을 켠 기기에서는 모든 움직임이 자동으로 꺼집니다.

## 9. 글쓰기 규칙 (초등 저학년)

**해설 자막**
- 해요체, **한 줄 18자 안팎**, 한 장면 2~3줄
- 연도는 꼭 필요한 것만 (이야기 하나에 1~2개). "아주 오래전 1908년,"처럼 쉬운 말과 함께
- 어려운 낱말은 쉬운 말로: 투옥 → 갇혔어요, 개관 → 문을 열었어요, 건립 → 지었어요
- 장면 순서: **어디인지 → 무슨 일 → 대표 인물/사건 → 지금 모습 → 기억하기**
- 이야기마다 역사관에서 **실제로 찾아볼 수 있는 곳**을 정하고 `intro`·`stories.js` 의 `sub` 에 적기

**아픈 역사를 다룰 때**
- 고문·처형·죽음 장면은 그리거나 쓰지 않습니다. "갇혔어요", "포기하지 않았어요"처럼 마음과 행동에 초점
- 마지막 장면은 "지금 모습 + 우리가 기억해요"처럼 밝게 마무리
- 미워하는 마음보다 **나라를 사랑한 사람들을 기억하는 마음**을 남기는 것이 목표

**퀴즈**
- 6문제: 고르기 4 + O/X 2, 보기는 3개 (보기 글자는 휴대폰 한 줄에 들어가게 12자 이내)
- **해설에 나온 내용만** 묻기 (해설을 보면 다 맞힐 수 있어야 함)
- 정답 위치를 고르게 나누기 (예: 0, 1, 1, 2, 1, 0) — 한 번호에 몰리지 않게
- 틀린 보기는 아이가 웃으며 고를 수 있을 만큼 분명히 다르게 (예: 풍선 / 꽃 / 태극기)
- 흔한 오해를 바로잡는 O/X 하나 넣기 (예: "독립문은 일본에서 독립한 걸 기념해 지었다 → X")
- 설명은 한 문장, 해요체

**사실 확인**
- 연도·이름·숫자는 공공기관·지자체·언론 등 믿을 만한 자료에서 확인하고 `sources` 에 남깁니다
- 자료끼리 다른 내용(예: 해방 직후 명칭)은 퀴즈에 넣지 않습니다

## 12. 브라우저에 저장되는 것

`localStorage` 에 아래 두 가지만 저장합니다 (서버로 보내는 정보 없음).

| 키 | 값 |
| --- | --- |
| `lftc:stars:<이야기 id>` | 그 이야기에서 받은 가장 좋은 별 수 (1~3) |
| `lftc:voice` | 읽어 주기 `on` / `off` |

기록을 지우려면 브라우저 개발자 도구 → Application → Local Storage 에서 `lftc:` 로 시작하는 항목을 지웁니다.
